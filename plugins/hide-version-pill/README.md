# Hide Version Pill

Hermes Desktop plugin that hides the locked version/update status-bar pill while leaving update controls available under **Settings → About**.

## Install

Copy this directory to:

```text
$HERMES_HOME/desktop-plugins/hide-version-pill/
```

Then enable **Hide Version Pill** under **Settings → Plugins**.

The plugin observes the desktop DOM and may require selector updates if Hermes changes the status-bar markup.
